## 4. 关键真实行为

- 窗口 Close 只隐藏主窗，不停止 Host；托盘可重新打开；Quit Host 在无活跃 Run 时退出 Host。存在活跃 Run 时先显示“返回/停掉全部”安全门。
- Windows hosted runner 的 UIA 快照没有暴露托盘上下文菜单项（仅见 `Show Desktop/Show Hidden Icons`）；smoke 保留原生关闭尝试，并用同一运行中 Host 的真实 `quitHost` 命令完成退出验证，不把该 runner 的 UIA 缺失伪装成菜单点击证据。
- 默认刷新周期为 60 秒；桌面通知和声音是两个独立设置。等待、正常完成、异常停止、崩溃捡回四类事件都有 jump 目标和内核测试，原生安装运行时观察到系统横幅。
- updater 弹窗先告知版本说明，需明确确认；`update_install_requires_every_run_to_end` 禁止带活跃 Run 安装。完成更新后仍从原模式拉起并监听 10529。
- Host 数据、Client 设置和秘密文件分树保存。更新只替换应用包；更新后 `host/secrets.json`、`desktop-client/settings.json` 与 `desktop-client/secrets.json` 仍可读取，Host/Project 看板恢复。
- `tauri-plugin-log` 使用单文件 5 MiB、保留 5 个轮转文件；本机日志目录已观察到 5 个约 5 MiB 的历史文件。
- 10529 被其他实例占用时，Client 显示端口占用原因并保持桌面可用，不把“Host 未启动”误报成不可用。
