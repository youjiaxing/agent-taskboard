# 产品壳主题记在 Client 上，出厂浅用暖纸、深用素纸夜间

v1 默认主壳共用一套 Codex 气质骨架（原生左侧栏、白主区、紧凑安静控件），观感用可替换主题清单。出厂三套：暖纸（仅白天工作台）、素纸、素纸夜间。不要暖纸夜间——深色只用素纸夜间。纸面书桌不再是默认骨架，暖纸仍留在清单里。

**主题**记在每个 Client 自己的本地设置里，值是一份具体主题，设置里没有「跟随系统」。这个 Client 还没有记下时，按系统浅/深匹配一次：浅 → 暖纸，深 → 素纸夜间，然后写成具体主题。之后只听这份记下的；改系统外观不会改应用。本机桌面窗口和 Host 托盘共用一份；桌面应用、电脑浏览器、手机浏览器各记各的。设置里是完整清单；顶栏浅/深是快切：深一律到素纸夜间，浅回到上次用的浅色（暖纸或素纸）。

骨架改写见 [原型：对照 Codex Desktop 再调默认主壳](https://github.com/youjiaxing/agent-taskboard/issues/31)。主题清单仍继承 [原型：默认主壳高保真观感方向](https://github.com/youjiaxing/agent-taskboard/issues/25)。

## Considered options

| 选项 | 未采纳原因 |
| --- | --- |
| 只锁一套不能换的皮肤 | 人要切浅/深，也要能把最初那套暖纸白天留在清单里 |
| 暖纸也做一套夜间 | 那版夜间不好看；深色另用素纸夜间 |
| 用改色覆盖掉暖纸 | 暖纸白天仍要可选，不能被素纸替换掉 |
| 设置里保留「跟随系统」 | 人选过之后应是具体主题；系统变了应用不应偷偷变 |
| 记在 Host 上，连它的 Client 共享 | 一个窗口连两份 Host 听谁的；和界面语言同一条理由 |

## Consequences

- `/to-spec` 按「默认骨架是 Codex 气质原生栏、清单可扩展、出厂三套、首次浅→暖纸 / 深→素纸夜间、各 Client 自记具体主题、设置 + 顶栏快切」写，不要发明账号级主题或「跟随系统」选项，也不要把纸面书桌写回默认骨架。
- 再加一套主题只加一份 token，不改主壳骨架。
