# 产品壳外观偏好记在 Client，并支持实时跟随系统

每个 Client 只持久化自己的外观偏好：跟随系统、素纸、素纸夜间或暖纸。第一次启动默认跟随系统；该偏好会随操作系统浅色或深色实时解析为素纸或素纸夜间，永不自动进入暖纸；手动选择另外三项后停止跟随。暖纸只有浅色形态，Embedded Terminal 始终使用固定深色，不随产品壳变化。

桌面窗口与 Host 托盘共用 `desktop-client/` 中的偏好；桌面浏览器和手机浏览器分别使用其来源站点的持久存储，不从 Host 快照选择浏览器外观。Client 只把解析后的浅色、深色或暖纸主题写入界面；旧 `warm-paper`、`plain-paper`、`plain-night` 值按新默认重置，不迁移、不保留兼容路径。

本决策由 [设计令牌的具体取值与命名 #136](https://github.com/youjiaxing/agent-taskboard/issues/136) 与 [Agent Taskboard 界面对齐改造规格 #145](https://github.com/youjiaxing/agent-taskboard/issues/145) 确认，取代本 ADR 原先“设置中没有跟随系统、首次按系统写入具体主题、之后不响应系统变化”的条款；每个 Client 自记、暖纸只有浅色、无账号级主题的原则保持不变。

## Considered options

| 选项 | 未采纳原因 |
| --- | --- |
| 首次按系统写入一项具体主题，之后不再跟随 | 操作系统变化后产品壳不会同步，且无法表达用户明确选择跟随系统 |
| 暖纸也做一套夜间形态 | 已确认暖纸只用于浅色；系统深色统一解析为素纸夜间 |
| 外观偏好记在 Host 上并让所有 Client 共享 | 一个 Client 可连接多份 Host，浏览器来源站点也应互不影响 |
| 保留旧主题值并迁移 | 产品仍是单用户阶段，直接按新默认重置比长期兼容路径更清楚 |
| 让 Embedded Terminal 跟随产品壳 | Agent 官方 TUI 的可读性与颜色语义需要稳定的固定深色画布 |

## Consequences

- Client 组件只消费语义令牌，不按主题名称写业务分支。
- 跟随系统只是一项持久偏好；解析结果属于当前 Client 的即时界面状态，不写入 Host 快照或设置文件。
- 新增主题只增加一组语义令牌，不改变主壳结构或终端配色。
