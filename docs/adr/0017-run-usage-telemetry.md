# 单次 Run 现场的多模型分轨用量与通路遥测

当用户盯着某一条 Run（Embedded Terminal 旁）时，展示该 Run 涉及模型的 token 用量与通路快慢（首字延迟 TTFT、生成速率及网络抖动）。

钉于 [原型：单次 Run 上如何展示多模型用量与通路快慢](https://github.com/youjiaxing/agent-taskboard/issues/42)。

## Considered options

| 选项 | 未采纳原因 |
| --- | --- |
| 合成一条「本次 Run 合计」 | 一个 Run 可能同时在用多个不同模型（主会话、子代理、中途换模型），混在一起会掩盖是谁在烧 token、是谁慢 |
| 仅显示单次最新首字/速率数值 | 无法感知网络抖动，偶发卡顿会被单点数值掩盖或误判为持久异常 |
| 在看板内管理或切换 Clash 代理节点 | 代理工具（如 Clash Verge）是用户自己的本机网络设施，看板不越界管理 |
| 把缺失字段算作 0 再加总 | 不符合真实口径，缺失字段严格以 `—` 表达 |

## Key Decisions

1. **摆位与交互**：
   - 默认采用**顶栏紧凑分轨（Variant A）**：终端顶部常态展示各模型极简胶囊，点击可展开多模型分轨卡片与 Sparkline 走势；
   - 备选提供**侧栏抽屉（Variant B）**与**底栏状态条（Variant C）**，供不同桌面工作流偏好选择。
2. **多模型独立分轨**：
   - 区分主会话模型、并发子代理模型与中途切换模型（标注已停用）；
   - 各模型独立展示 Token 六字段（input / output / cacheRead / cacheWrite / reasoning / total，缺失为 `—`）；
   - 绝不做虚假的跨模型加总。
3. **「最近」与抖动感知**：
   - 使用「最近 10 次调用微型 Sparkline 柱状图 + 抖动偏慢标黄/标红」表达；
   - 直观判断是偶发网络抖动还是持续降速，偏慢时给出本机代理通路提示。
4. **双向跳转**：
   - Run 观察条提供 `[Host 用量 ↗]`，直达 Host 级用量页并高亮该 Run；
   - Host 用量流水提供 `[打开此 Run 终端 ↗]`，一键切回看板并聚焦终端。
5. **手机端**：
   - 手机端默认展示当前主要模型胶囊，并支持展开简易多模型 Token 列表；完整 6 字段分轨与 Sparkline 走势图引导至电脑桌面端查看。

## Consequences

- `/to-spec` 按「终端顶栏紧凑分轨、展开多模型卡片、近 10 次调用 Sparkline 抖动图、缺失字段显示 `—`、与 Host 用量页双向跳转、手机端支持简易折叠多模型列表」撰写。
