# 主壳使用固定区域、内部页面状态和当前 Host 侧栏

v1 每天使用的主壳采用一次性冻结的 Codex Desktop 结构气质，但保留 Agent Taskboard 的 Issue、Run、Host 和 Project 产品模型。

**全局顶栏**跨看板、依赖图、专注工作区、设置、Host 总览和用量保持恒定。它只放侧栏开关、按需出现的返回、只读当前对象身份、右栏开关、查看改动开关、外观、设置和更多菜单。Project 名称、看板/依赖图切换、新建、刷新和搜索属于每页内容工具行，同一个控件不在两处重复。

**左侧栏**顶部是一行当前 Host 切换器，下面只列当前 Host 的 Project 和 Run。Host 总览与用量仍是 Host 级页面，不跨 Host 汇总。侧栏收起后由全局顶栏恢复。

**Client 内部页面**由 Client 本地视图状态组合，不使用 URL 路由。Host 的每 Client 导航镜像继续保存当前 Host、Project、Issue、Run、搜索/筛选、`centerView` 和 `workspaceView`；Host 快照仍是业务真源。Client 本地状态只保存一级页面、返回点、滚动或图视口记忆、草稿和固定面板状态。进入设置、Host 总览、用量或专注工作区后返回，恢复来源页面和相关视图状态；浏览器地址保持不变。

**设置**是桌面应用、桌面浏览器和手机共用的可返回整页，不是原生新窗口或遮罩弹层。外观、语言、启动、更新、刷新间隔、通知和 Host 设置按分区保留。

**专注工作区**使用固定归属区域。Embedded Terminal 始终位于主区；桌面右侧在窄栏与查看改动宽面板之间切换。面板按 Client 只保存可见性和受限宽度；越界宽度夹紧，损坏状态恢复默认，不保存 `x/y`、高度、浮动坐标或覆盖关系。活跃 Run 可以使用独立原生窗口，但这不等于内容区自由浮窗。

**手机**使用单任务页面和抽屉式范围切换，不压缩桌面多面板；完整查看改动不在手机提供。

这取代本 ADR 旧版本中的「Host 不在顶部切换」「Terminal 默认停靠在底栏」「内容区可自由拖动、浮窗或覆盖」以及「手机固定为看板｜票｜Run 三项底栏」条款。看板默认、Host 总览独立、Issue/Run 生命周期、官方 Agent CLI TUI 和当前 Host 作用域继续有效。

## Considered options

| 选项 | 未采纳原因 |
| --- | --- |
| 把会话列表和聊天当首页 | 产品工作单元是 Issue，不是聊天线程 |
| 用 URL 承担 Client 内部页面 | 当前合同不承诺后退、深链接或刷新恢复；会把本地页面组合与 Host 导航镜像耦合 |
| 设置继续使用遮罩弹层 | 无法提供一致的一级页面返回，也容易丢失来源筛选、滚动和选择 |
| 保留自由拖动布局并迁移旧坐标 | 固定区域已取代任意坐标；迁移会延续被废止的合同 |
| 在侧栏混合多个 Host 的 Project 和 Run | 破坏当前 Host 作用域，容易把不同 Host 的业务状态误读为同一列表 |

## Consequences

- 主壳渲染必须明确区分全局顶栏和内容工具行的控件归属。
- `PrimaryPage` 与返回点是 Client 展示状态，不复制 Issue、Run、Project 或 Host 业务数据。
- 设置、Host 总览和用量通过产品界面进入与返回，内部切换不改变浏览器地址。
- 固定区域持久化数据只能包含可见性和合法宽度；旧自由布局键直接丢弃，不迁移。
- 桌面与紧凑桌面在 `640px` 和 `900px` 边界连续；手机从 `639.98px` 以下开始。
- 看板、依赖图、专注工作区和手机的后续改造继续复用这一主壳与内部视图状态，不另建并行导航路径。
