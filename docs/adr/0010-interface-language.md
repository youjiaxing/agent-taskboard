# 界面语言记在 Client 上，只译产品壳

v1 产品壳提供简体中文与英语。简体中文是源文案，英语是完整译文；用词打架改英语，以后加语言从中文译。只译按钮、分区名、空状态、设置、配对说明、Host 托盘；不译 Tracker 上 Issue 的标题/正文/评论、Embedded Terminal 里的官方 TUI、git / 远端 API 的原始报错。

**界面语言**记在每个 Client 自己的本地设置里，值是一项具体语言，设置里没有「跟随系统」。这个 Client 还没有记下时，按系统匹配一次：任何中文 → 简体中文，任何英文 → 英语，其它（如意大利语）→ 英语，然后写成具体语言。之后只听这份记下的；改系统语言不会改应用。浏览器以浏览器自己的语言当作系统语言。本机桌面窗口和 Host 托盘共用一份；桌面应用、电脑浏览器、手机浏览器各记各的。一个窗口连多份 Host，产品壳仍是这一份界面语言，各 Host 上的 Issue 仍是仓库原文。没有产品账号，所以这不是登录偏好。界面语言是 Client 设置里的一项，落点见 [设置与数据存放位置](./0012-settings-and-data-location.md)。

这钉住了 [决策：Client / Host 界面多语言](https://github.com/youjiaxing/agent-taskboard/issues/24)。

## Considered options

| 选项 | 未采纳原因 |
| --- | --- |
| v1 只出中文、不做切换 | 开源项目一开始就要有多语言接法；中文必须是完整一等语言，不是以后再补 |
| v1 再加繁体或其他语言 | 你不日常用；机制已允许以后加一份目录 |
| 英语当源文案 | 作者能把关的是中文；中文不能变成后补翻译 |
| 两边并列、没有源 | 两份文案会各写各的，以后加语言也不知道抄哪边 |
| 设置里保留「跟随系统」 | 人选过之后应是具体语言；系统变了应用不应偷偷变 |
| 每次启动都重新跟系统 | 切了记不住，等于没切换 |
| 记在 Host 上，连它的 Client 共享 | 一个窗口连两份 Host 听谁的；用英文系统遥控中文 Host 会被拽走 |
| 窗口一份、托盘一份 | v1 没有这种需求；改了窗口托盘还是另一种像没改干净 |
| 托盘永远跟系统 | 等于把「跟随系统」从后门放回来 |
| 翻译 Issue 原文或官方 TUI | 和仓库 / GitHub 对不上；官方 TUI 必须原样呈现 |

## Consequences

- `/to-spec` 按「产品壳可切换、中文为源、各 Client 自记具体语言、首次按系统匹配」写，不要发明账号级语言偏好或「跟随系统」选项。
- 界面语言落在 Client 设置（本机窗口与托盘共用的那份），见 [0012](./0012-settings-and-data-location.md)。
- 主界面设置里语言只有「简体中文」和「English」两项。见 [原型：主界面信息架构低保真方案](https://github.com/youjiaxing/agent-taskboard/issues/14) / [决策：主界面信息架构定稿](https://github.com/youjiaxing/agent-taskboard/issues/15)。
